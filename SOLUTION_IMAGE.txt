🔍 DEBUGGING SI PROBLÈME
───────────────────────────────────────────────────────────────────────────

1. Vérifier l'image source :
   ls -lh /home/kali/portfolio/public/profile.jpg

2. Vérifier après build :
   npm run build
   ls -lh /home/kali/portfolio/dist/profile.jpg

3. Lancer le test automatique :
   ./test-image.sh

4. Dans le navigateur (F12) :
   - Onglet Network : vérifier que profile.jpg est demandé
   - Onglet Console : vérifier les erreurs JS
   - Si erreur 404 : vérifier le chemin complet dans Network

5. Forcer le rechargement du cache :
   Ctrl + Shift + R (ou Cmd + Shift + R sur Mac)
